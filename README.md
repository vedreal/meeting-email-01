Entry for the [make.fun bounty "The Meeting That Should Have Been an Email"](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

## The entry

`main.py` writes ten fresh one-liner candidates about a meeting that should
have been an email, scores each against the judge's published criteria
(on-topic, laugh, surprise, economy, recognition — weighted 5/4/3/2/1), and
writes the highest-scoring line to `/output/entry.txt`.

The winning line:

> I joined the meeting from my car, muted, and emailed my apologies for missing it while I was in it.

## Run

```sh
python3 main.py
```
